# Win95 CRT Power Button

![Win95 CRT Power Button](https://media.gsartori.com/skills/win95-botao-crt/cover-a74f5a66.avif)

A miniature CRT monitor. On hover, phosphor opens from a point into a line and a picture. Press the button to light up the screen and reveal a tiny desktop.

A miniature CRT monitor. On hover, phosphor opens from a point into a line and a picture. Press the button to light up the screen and reveal a tiny desktop. Use it as an entry or launch button for a retro experience.
