# Lap counter

![Lap counter](https://media.gsartori.com/skills/palma-odometer/cover-b9886179.avif)

Add or subtract laps and watch individual mechanical drums turn.

Add or subtract laps while mechanical drums turn only the digits that change, from zero to 999. Use it for counters and quantity pickers, such as items in an order, points on a scoreboard or completed steps. An interactive piece from the GTA 6 design system with keyboard and reduced-motion support.
