# Boarding coupon

![Boarding coupon](https://media.gsartori.com/skills/palma-ticket/cover-6995da16.avif)

Validate a boarding pass to tear away its stub and expose a registered seal.

Validate a boarding pass to tear away its stub and expose a registered seal; tapping the stub restores it. Use it to confirm an action in a memorable way, such as a check-in, a registration or a used ticket. An interactive piece from the GTA 6 design system with keyboard and reduced-motion support.
