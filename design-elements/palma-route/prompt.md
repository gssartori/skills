# Radar destination

## Look

Draw an engraved round street map with a tidal shoreline, a warm bezel, a fixed position arrow and three labelled destination controls. Use the cool map as ground and one pale route as the highlight.

## Interaction

Selecting a destination changes both the endpoint and the actual path traced through the streets. Only one destination is selected. Preserve the visible route at rest and make it immediately available under reduced motion.

## Delivery

Deliver a standalone offline HTML component with inline CSS, original vector art and local JavaScript. Use Brazilian Portuguese labels for this deployment. Keep the control bounded inside its gallery frame. Provide a visible keyboard focus state, touch operation and an immediate transition for reduced motion. Hover adds feedback without carrying any essential action. Use no network requests or browser storage.
