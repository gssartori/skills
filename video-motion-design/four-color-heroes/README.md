# Four-Color Heroes

![Four-Color Heroes](https://media.gsartori.com/skills/four-color-heroes/cover-0c22fefc.avif)

Vídeo de gibi de super-herói clássico: retícula, quatro cores e uma capa no final.

Monta um filme animado em JavaScript (1920×1080, com banda de metais) no estilo dos gibis de super-herói impressos em quatro cores: retícula, letreiros que explodem, um herói para cada parte do assunto e uma capa com raios no final. Você descreve o assunto e o prompt monta a revista.

## Como usar

O prompt está em [prompt.md](prompt.md).

Copie o prompt, troque a parte de Content pelo assunto do seu vídeo e mande para a sua IA (Claude, Gemini, ChatGPT ou Kimi). Ela entrega um arquivo HTML que toca com som e pode virar MP4.

Funciona em: Claude, Gemini, ChatGPT, Kimi.

Prévia e detalhes: https://gsartori.com/skills/four-color-heroes
