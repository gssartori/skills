# Estilos de vídeo

Estilos de vídeo animado do Gabriel Sartori: cada um transforma qualquer assunto num filme curto, com som, num visual próprio.

## Instalar tudo no Claude Code

```text
/plugin marketplace add gssartori/skills
/plugin install gs-motion@gsartori
```
