# Textbook Cutaway

![Textbook Cutaway](https://media.gsartori.com/skills/textbook-cutaway/cover-1cf564ed.avif)

Vídeo de prancha de livro didático: um bloco em corte, com camadas, dutos e legendas exatas.

Monta um filme animado em JavaScript (1920×1080, com som) como uma prancha de livro de ciências: o assunto vira um bloco cortado ao meio, montado camada por camada, com um fluxo quente correndo pelos dutos e cada parte nomeada por uma linha de chamada. Você descreve o assunto e o prompt monta a prancha.

## Como usar

O prompt está em [prompt.md](prompt.md).

Copie o prompt, troque a parte de Content pelo assunto do seu vídeo e mande para a sua IA (Claude, Gemini, ChatGPT ou Kimi). Ela entrega um arquivo HTML que toca com som e pode virar MP4.

Funciona em: Claude, Gemini, ChatGPT, Kimi.

Prévia e detalhes: https://gsartori.com/skills/textbook-cutaway
