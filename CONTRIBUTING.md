# Contributing

Anyone can propose a piece for a design system: a basic component (button, toggle, checkbox, loader, tooltip, table and others) or a special piece, the striking one that defines the style.

1. Open an issue with the "Propose a piece for a design system" form: https://github.com/gssartori/skills/issues/new?template=propose-piece.yml

2. Say which design system it belongs to, what kind of piece it is, the prompt or instructions that produce it, and a single HTML file (or a link) that shows it working.

3. Gabriel Sartori reviews every proposal. Approved pieces are published on gsartori.com and in this repository with credit to you.

## Rules for a piece

- Follow the rules.md of the design system.

- One HTML file, no external requests, no browser storage, at most 60 KB, and it respects reduced motion.

- Only send work you made or have the right to share.
