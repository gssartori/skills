# Win95 Framed Pixel Flag

Build this component for my project. Ask where it will be used if that changes the implementation. Use the linked single-file reference for the interaction and adapt it to my layout. Provide dependency-free HTML, CSS and JavaScript or an equivalent component for my stack.

## Look

Draw a free-floating four-pane flag on a low-resolution canvas inside a raised grey button frame with a recessed inner panel. Use crisp pixel strips, a short pixel trail and light and shade across the cloth.

## Motion

Let hover and focus build a rolling wave in the fabric. A press gives the cloth a stronger impulse and depresses the housing. Dampen the wave back to rest after the interaction ends. Keep the flag at the same height throughout.

## Accessibility

Use a named native button with a visible focus ring. The canvas is decorative. With reduced motion, display the still flag and keep the pressed bevel as feedback.

## Customize

Expose the label, four cloth colors, panel color, wave strength, damping and the action callback.
