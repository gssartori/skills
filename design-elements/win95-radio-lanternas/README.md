# Win95 Lantern Radio Group

![Win95 Lantern Radio Group](https://media.gsartori.com/skills/win95-radio-lanternas/cover-4ec73f9d.avif)

Three hanging lanterns act as exclusive choices. Select a lamp to give it a brief swing and light it in amber, cyan or green.
