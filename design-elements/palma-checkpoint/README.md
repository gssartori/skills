# Checkpoint stamp

![Checkpoint stamp](https://media.gsartori.com/skills/palma-checkpoint/cover-edf852f0.avif)

Mark or clear a return point by seating a brass stamp.

Mark or clear a return point by seating a brass stamp that swaps its flag for a check. Use it to save, bookmark or mark as done an item, a step or a page. An interactive piece from the GTA 6 design system with keyboard and reduced-motion support.
