# Checkpoint stamp

## Look

Build a reversible bookmark action as a plum enamel ticket, with a tilted brass die on its left and a pale italic label on the right. Use an inset cut-corner plate, contrasting lip and a thin register line.

## Interaction

Use a real toggle button. On marking, seat the die, replace its flag with an engraved check, extend the register line and display the marked label. Pressing again clears it. Connect aria-pressed to the saved state. Where a host provides persistence, let its result control the confirmation.

## Delivery

Deliver a standalone offline HTML component with inline CSS, original vector art and local JavaScript. Use Brazilian Portuguese labels for this deployment. Keep the control bounded inside its gallery frame. Provide a visible keyboard focus state, touch operation and an immediate transition for reduced motion. Hover adds feedback without carrying any essential action. Use no network requests or browser storage.
