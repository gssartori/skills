# Garage shutter

## Look

Use a ribbed roll-up door as the cover of a narrow disclosure panel. The lintel is an interactive tab. Inside, illustrate an original coral coupe in side view with a cabin, separate rims and a contact shadow.

## Interaction

Make the lintel a disclosure button with aria-expanded and aria-controls. Raising the door reveals the vehicle and its name. Closing it covers both, synchronizes accessibility, and reverses smoothly if toggled mid-travel.

## Delivery

Deliver a standalone offline HTML component with inline CSS, original vector art and local JavaScript. Use Brazilian Portuguese labels for this deployment. Keep the control bounded inside its gallery frame. Provide a visible keyboard focus state, touch operation and an immediate transition for reduced motion. Hover adds feedback without carrying any essential action. Use no network requests or browser storage.
