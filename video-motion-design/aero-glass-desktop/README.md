# Aero Glass Desktop

![Aero Glass Desktop](https://media.gsartori.com/skills/aero-glass-desktop/cover-f6ec35e4.avif)

Vídeo dentro de uma área de trabalho de vidro do fim dos anos 2000: janelas translúcidas, brilho de aurora e barra de tarefas.

Monta um filme animado em JavaScript (1920×1080, com som) como se tudo acontecesse num sistema operacional de vidro fosco do fim dos anos 2000: janelas com reflexo na diagonal, faixas de luz de aurora, pilhas de janelas em perspectiva e um botão iniciar luminoso. Piano elétrico suave por baixo. Você descreve o assunto e cada parte vira uma janela.

## Como usar

O prompt está em [prompt.md](prompt.md).

Copie o prompt, troque a parte de Content pelo assunto do seu vídeo e mande para a sua IA (Claude, Gemini, ChatGPT ou Kimi). Ela entrega um arquivo HTML que toca com som e pode virar MP4.

Funciona em: Claude, Gemini, ChatGPT, Kimi.

Prévia e detalhes: https://gsartori.com/skills/aero-glass-desktop
