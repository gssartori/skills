# Mode wheel

## Look

Make a handheld dial on a slate field. Divide the annular selector into six clickable wedges with separate line icons for map, radio, camera, music, marina and garage. A raised brass-rimmed central hub displays the selected mode.

## Interaction

Open the ring outward from the hub, leaving space between wedge tips. Give the focused sector a warmer edge. Pointer selection commits and closes. Arrow keys move focus inside the open control, Enter or Space commits, Escape cancels, and focus returns to the hub. Hide the sectors from interaction and accessibility while closed.

## Delivery

Deliver a standalone offline HTML component with inline CSS, original vector art and local JavaScript. Use Brazilian Portuguese labels for this deployment. Keep the control bounded inside its gallery frame. Provide a visible keyboard focus state, touch operation and an immediate transition for reduced motion. Hover adds feedback without carrying any essential action. Use no network requests or browser storage.
