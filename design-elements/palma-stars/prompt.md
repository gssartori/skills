# Alert stars

## Look

Cut five distinct five-point stars into a narrow warm metal strip. Empty stars have low-luminance fill and a visible edge. Filled stars take a small amber highlight, like signal lamps on an instrument.

## Interaction

Build one radio group with five named levels. Selecting a position checks that radio and lights it together with all preceding stars. A single light pulse signals the selected level. Native radio keyboard navigation and labels must remain usable.

## Delivery

Deliver a standalone offline HTML component with inline CSS, original vector art and local JavaScript. Use Brazilian Portuguese labels for this deployment. Keep the control bounded inside its gallery frame. Provide a visible keyboard focus state, touch operation and an immediate transition for reduced motion. Hover adds feedback without carrying any essential action. Use no network requests or browser storage.
