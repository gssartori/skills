# Regatta standings

![Regatta standings](https://media.gsartori.com/skills/palma-regatta/cover-1f17b261.avif)

Sort boats by finish time and follow each row into its new rank.

Sort boats by finish time and follow each table row into its new rank. Use it for rankings and tables that need sorting, such as results, scoreboards or comparisons. An interactive piece from the GTA 6 design system with keyboard and reduced-motion support.
