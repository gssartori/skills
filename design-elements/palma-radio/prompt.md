# Waterfront tuner

## Look

An analog dash receiver has a lettered station name, a monospaced frequency display and a glowing vertical needle over engraved tick marks. Use plum-matte metal, a pale brass scale and one focused warm light.

## Interaction

Use a native range with four discrete stops. Moving or keying the slider synchronizes the needle, station name and frequency. Provide a readable value for assistive technology. The example selects fictional stations silently.

## Delivery

Deliver a standalone offline HTML component with inline CSS, original vector art and local JavaScript. Use Brazilian Portuguese labels for this deployment. Keep the control bounded inside its gallery frame. Provide a visible keyboard focus state, touch operation and an immediate transition for reduced motion. Hover adds feedback without carrying any essential action. Use no network requests or browser storage.
