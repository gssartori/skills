# Lap counter

## Look

Set three mechanical number drums between a pair of minus and plus buttons in a small metal dashboard housing. Split each face into two subtly different planes and warm the units wheel.

## Interaction

Increment or decrement one lap per action. Animate only digits that actually change, including carries, and clamp the range from zero to the largest three-digit value. Disable the appropriate end-stop button. Keep the numeric result in a labelled output.

## Delivery

Deliver a standalone offline HTML component with inline CSS, original vector art and local JavaScript. Use Brazilian Portuguese labels for this deployment. Keep the control bounded inside its gallery frame. Provide a visible keyboard focus state, touch operation and an immediate transition for reduced motion. Hover adds feedback without carrying any essential action. Use no network requests or browser storage.
