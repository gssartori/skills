# Mode wheel

![Mode wheel](https://media.gsartori.com/skills/palma-radial/cover-0f0e99e6.avif)

Open a radial dial and choose one of six illustrated modes.

Open a radial dial and choose one of six illustrated modes, with the hub showing the current choice. Use it as a quick menu to switch sections, tools or modes in an app, a game or a presentation. An interactive piece from the GTA 6 design system with keyboard and reduced-motion support.
