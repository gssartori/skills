# Win95 Lantern Radio Group

Build this component for my project. Ask where it will be used if that changes the implementation. Use the linked single-file reference for the interaction and adapt it to my layout. Provide dependency-free HTML, CSS and JavaScript or an equivalent component for my stack.

## Look

Hang three pixel-shaped metal lanterns from a narrow rail. Use separate amber, cyan and green colors and include a small radio indicator below each lamp.

## Motion

Keep one light on. Changing the selection lights the chosen lamp and its pool of light and turns the previous lamp off. Let the selected lantern swing briefly around the top of its chain.

## Accessibility

Use native radios with one shared name and a group label. Support arrow keys, Home and End, and keep a visible focus outline. With reduced motion, update the light and radio indicator instantly.

## Customize

Expose option labels, colors, initial selection and a change callback.
